# Tài liệu sử dụng

Nguồn chính: báo cáo BTL 41 trang đề 23, MSSV B23DCCN876 do người dùng cung cấp; Câu 4.b, Bảng 4.1/4.3/5.2, Hình 4.5–4.10. Nghiệp vụ và code cốt lõi không thay thế bằng mẫu từ mạng.

Nguồn chính thức dùng cho cấu hình build/triển khai (đối chiếu 12/11/2026):

- Apache Maven WAR Plugin: https://maven.apache.org/plugins/maven-war-plugin/usage.html
- Tomcat 9 / Java EE: https://tomcat.apache.org/whichversion.html
- Docker Official Image Tomcat: https://hub.docker.com/_/tomcat
- Docker Official Image MySQL: https://hub.docker.com/_/mysql
- Docker Official Image Maven: https://hub.docker.com/_/maven
- GitHub checkout: https://github.com/actions/checkout
- GitHub setup-java: https://github.com/actions/setup-java
- GitHub upload-artifact: https://github.com/actions/upload-artifact

Các image dùng tag nhánh 9.0/8.4/3.9, có thể nhận bản vá trong nhánh. Connector/J giữ 8.4.0 theo cấu hình báo cáo. Đây không phải tuyên bố rằng mọi phiên bản trên là phiên bản mới nhất.
